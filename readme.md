# Praan AI/ML Intern Task: Video to 3D Point Cloud Pipeline

This repository contains my submission for the Praan AI/ML Intern Task. It includes two distinct approaches to reconstruct a 3D point cloud from a monocular handheld video (`sample.mp4`) using state-of-the-art depth estimation models.

## 📁 Repository Structure

```text
.
├── approach1_extracted_frames/ # Auto-generated folder containing frames from Approach 1
├── approach1_output.png        # Screenshot of the 3D point cloud generated by Approach 1
├── approach1.py                # Pipeline using Depth Anything V2 (Relative Depth + Cylindrical Projection)
├── approach2_output.png        # Screenshot of the 3D point cloud generated by Approach 2
├── approach2.py                # Pipeline using ZoeDepth (Metric Depth + Spherical Projection)
├── Report.pdf                  # Detailed technical explanation and comparison of both approaches
├── requirements.txt            # Python dependencies required to run the codebase
├── room_cylindrical.ply        # Output 3D point cloud from Approach 1
├── room_zoedepth.ply           # Output 3D point cloud from Approach 2
├── sample.mp4                  # Input 30-60 second handheld video
└── visualization.py            # Script to visualize the generated .ply files
```

## ⚙️ Setup & Installation

### 1. System Requirements

- **Python:** 3.8 to 3.10 recommended.
- **FFmpeg:** Both scripts use ffmpeg to extract frames. You must have FFmpeg installed and added to your system's PATH.
  - **Windows:** `winget install ffmpeg` (or download from [gyan.dev](https://www.gyan.dev/ffmpeg/builds/))
  - **Linux:** `sudo apt install ffmpeg`
  - **macOS:** `brew install ffmpeg`

### 2. Install Python Dependencies

Create a virtual environment (optional but recommended) and install the required packages:

```bash
pip install -r requirements.txt
```

> **Note:** Approach 2 uses ZoeDepth, which strictly requires `timm==0.6.7`. Ensure this version is installed via the requirements file to avoid `state_dict` loading errors.

## 🚀 How to Run the Code

Make sure `sample.mp4` is located in the root directory before running the scripts.

### Run Approach 1 (Depth Anything V2)

This approach uses a lightweight model for relative depth estimation and projects the stitched panorama using a cylindrical projection.

```bash
python approach1.py
```

- **What it does:** Extracts frames to `approach1_extracted_frames/`, stitches them into a panorama, estimates depth, and saves the output.
- **Output:** `room_cylindrical.ply`

### Run Approach 2 (ZoeDepth)

This approach uses an indoor-specific model for real-world metric depth estimation (in meters) and projects the scene using a spherical projection.

```bash
python approach2.py
```

- **What it does:** Extracts frames (cleaning up intermediate files automatically), stitches them, downloads ZoeDepth weights (if running for the first time, ~1.4GB), estimates depth, and saves the output.
- **Output:** `room_zoedepth.ply`

## 👁️ How to Visualize the Outputs

You can view the generated 3D point clouds in two ways:

### Method 1: Using the provided visualization script

Run the included Python script to interactively view the `.ply` files:

```bash
python visualization.py
```

### Method 2: Using Professional 3D Software

For the best viewing experience, including the ability to inspect point density and real-world scale, you can open `room_cylindrical.ply` or `room_zoedepth.ply` using free industry-standard software:

- [MeshLab](https://www.meshlab.net/) (Recommended)
- [CloudCompare](https://www.cloudcompare.org/)
